# 日文課堂筆記產生：交接說明

把這份說明連同 build_note.py、note_L33_trial.json（以及逐字稿 .srt）一起上傳到新的工作階段，請 Claude 先讀這份。

## 目標
從帶時間戳的課堂逐字稿，產生與範例講義（L23–L25，2026/3/25–4/22）同樣撰寫邏輯與版面的筆記，輸出為可編輯的 Word。

## 規則（使用者已決定）
- 三階段：1 列出要收進筆記的項目（類型＋時間範圍）→ 2 撰寫內容 → 3 組版成 Word。每階段完成後等使用者確認，不得自行跨階段。
- 正文比照原版：詞卡、表格、短句＋一行中文；不放時間戳、不敘述課堂經過。不確定的內容只放文末「待確認清單」。
- 順序：課外補充在前，再依課本順序（單字、文型與例文、會話、小文章、練習）。
- 聲調：目前一律以 0 號音（平板）繪製；未來由 schema 提供號數後重新產生。
- 插圖：預設只用いらすとや；查不到才用其他可免費使用的圖，並在框內與待確認清單註明來源。動詞與抽象詞不配圖（比照原筆記）。

## 產生器 build_note.py
`python3 build_note.py note.json out.docx`
- 聲調線：每拍一個表格小格，上方讀音列的上緣紅線＝高音，右緣紅線＝下降；助詞依前一片段承接（平板後高、有下降後低）。
- 日文行寫法：片段用「／」分隔；{漢字|讀音}；+助詞（讀音不同寫 +は=わ）；#n 指定號數；!、 標點；@A： 標籤。
- 區塊：title、tag、cards（詞卡，illust 可為 null／關鍵字／{source,title,url[,image]}；有 image（圖片網址或本機路徑）時嵌入圖片，網址會快取到 images/，下載失敗退回文字佔位框）、defs、sentences、note（＊註解）、pending（待確認頁）。
- 字型取自原 PDF：日文 Yu Gothic UI 14pt、讀音 8pt、中文 清松手寫體1 12pt 藍 #0070C0、標題 源石黑體 M、表頭底色 #DEEAF6、框線 #E8E6E6、紅線 #FF7D80。
