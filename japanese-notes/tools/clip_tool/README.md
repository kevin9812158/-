# 音檔切割工具（本地網頁）

在自己的電腦上，照切點表把課堂錄音切成一句一句的音檔。只在本機運作，錄音不會上傳。

## 第一次準備
需要 Python 3.8 以上和 ffmpeg（指令列可以執行）。不知道電腦裡有沒有，先雙擊 `japanese-notes/local/盤點電腦環境.bat` 確認。
只用 Python 內建功能，不需要安裝套件；在 `japanese-notes/local` 用 uv 管理的話，也可以 `uv run pipeline.py tool <課資料夾>` 開啟。

## 每次使用
1. 準備一個資料夾，放入：
   - 課堂音檔（例：`PassFab20261006_183938033_1.m4a`）
   - 切點表（例：repo 裡的 `japanese-notes/online/poc_page1_cuts.tsv`）
   - `clip_tool.py` 和 `開啟切割工具.bat`
2. 雙擊 `開啟切割工具.bat`，瀏覽器會打開工具頁面（http://127.0.0.1:8765）。
3. 在頁面上：
   - 選音檔、選切點表
   - 每一句按「▶ 試聽」；起點／終點可以直接改，或按 −0.1／+0.1 微調
   - 勾選要的句子，按「切割並下載 zip」
   - 改過切點的話，按「儲存修改的切點表」，會另存成 `原檔名_edited.tsv`
4. 切好的檔案也會留在資料夾裡的 `exports/<切點表名稱>/`，附 `清單.csv`。

關掉黑色視窗就會結束工具。

## 切點表格式
tab 分隔，第一列是欄名。必要欄位：`start`、`end`（時:分:秒.毫秒，例 `0:17:51.910`）。
選用欄位：`no`（編號）、`text`（句子）、`speaker`（說話者）、`usable`（Y／N，N 預設不勾）、`note`（備註）。

## 說明
- 切割一律重新編碼，起訖精確到毫秒（不會因為只能在關鍵影格切而偏移）。
- 匯出檔名：`編號_說話者_句子.m4a`（也可選 mp3、wav）。
- 之後要加的步驟（自動辨識、找切點、判斷說話者）會加在同一個頁面。
