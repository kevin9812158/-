# 撰寫邏輯與取捨習慣

以下內容從本 skill 原作者的一套講義範本歸納而來。你的使用者的範本風格可能不同：第一次使用時照 `references/setup.md` 的「範本對照」整理，不一致的地方以使用者的範本為準。

## 範本頁面對照

第一次拿到使用者的範本時，整理一張這樣的表，給使用者確認後再開始寫：

| 範本 | 頁碼與內容 |
|---|---|
| （檔名） | p1：課外補充詞卡（含片假名、配圖）＋詞卡下方的 • 例句<br>p2：主題表（例：擬聲擬態語）、小文章<br>… |

需要看範本時，只看對應的那一頁。

## 單元順序

1. 每課先放「課外補充」，也就是老師補充、課本沒有的內容。
2. 接著照課本順序：單字 → 文型＆例文 → 會話 → 小文章 → 練習。
3. 課本單元的標題是「大家的日本語 L??」，下面接黃底子標籤（單字、文型＆例文…）。

## 各類內容怎麼寫

- **單字**
  - 課本單字加編號（2. 3. …）；老師補充的詞，前面標圓圈「補」。
  - 成對的詞並排在同一列，例如 直す／直る、連れて行く／連れて来る。
  - 動詞寫成「辭書形・ます形＋中文」，例句直接放在同一格裡，用 • 列出。
  - 名詞、片假名外來語做成詞卡配插圖，例句放在詞卡下方，用 • 列出。
  - 動詞和片假名外來語一定要收，這是 N4 以上的重點。
- **課外補充**的固定組合是三樣：
  - 詞卡
  - 「「XX」的說法」主題表：兩欄對比（例如 較正式／較口語），或「左欄詞＋中文、右欄例句」（例如 擬聲擬態語）
  - 灰色表頭的「短句練習」表
- **文型**依序寫：模板 → 一個代表例句 → 編號注意事項 → 變化 → 練習。沒有的環節就省略。
- **成對概念**（くれる／もらう、自動詞／他動詞、較正式／較口語）並排成兩欄表格。
- **例句**：老師舉的例句幾乎全收（範本「年を取ってから…」收了 6 句），每句只配一行短中文（台灣口語、藍色）。
- **練習**只收句子本身。兩兩對話、換算遊戲、A／B 角色扮演這類課堂操作都不收。
- **＊註解**（橘色）只用在三種情況：用法限制、語感差異、發音連音。內容必須是老師講過的，一句話寫完。
- **語感補充**比較短的話，接在中文後面，用橘色短箭頭寫，例如「→口語：朋友、親人間常用」。
- **助詞重點**：教學目標的助詞（例如 で／に／を 的對比）加淺黃色螢光。

## 取捨原則

- 這是複習筆記，不是課堂紀錄。不敘述老師說了什麼、不逐段摘要，正文也不放時間戳。
- 同一個主題的零散內容，要併成一張表，不要照上課順序拆成好幾段。
- 老師口誤或辨識錯字：正文寫更正後的日文，「原辨識→更正」列進待確認清單。
- 不確定的內容不寫進正文，正文也不加「待確認」字樣。一律只列在文末的待確認清單，格式是「時間｜問題｜需要補充什麼」。

## 待確認清單：依風險分流，不縮短

所有項目都保留，只是依風險排序，讓使用者先審最可能出錯的。每一條都要標**風險等級**和**依據來源**，格式是：

`【等級】項目｜依據（來源）｜要使用者做什麼`

例：`【高】割引は八時から始まります｜MCP：phrase_accent_unresolved，助詞は回傳低（依規則平板後應高）｜請核對`

note.json 裡可以寫成字串（開頭加「【高】」），也可以寫成 `{level, item, basis, action}`。產生器會依 高→中→低 排序，同等級維持原順序；沒標等級的會當「中」並提出警告。

| 等級 | 放什麼 |
|---|---|
| **高**（最先審） | MCP 有 warnings、accent 為 null 或 needsReview 為 true；MCP 結果和範本紅線或已知資料不一致（例：ガチョウ肉，MCP 拆成兩段，範本是 2 號）；同一個詞在不同查詢裡結果不一致（例：割引 單獨查 `[0,1,1,2]`、句中 `[0,1,1,1]`）；依規則推算補上的部分（例：句中助詞的高低）；還沒取得聲調資料、暫畫 0 號音 |
| **中** | 逐字稿辨識錯字、依上下文還原的內容；辨識不清而沒收錄的內容；課本編號未知、是否為補充詞這類內容判斷 |
| **低**（最後看，照樣列出） | MCP 沒有警告、needsReview 為 false 的結果（伺服器有把握，但仍只是預測）；插圖暫代這類不影響正確性的項目 |

聲調的逐條審閱不放在 Word 裡，而是在對話中用風險分流對照表進行（`scripts/review_list.py`，見 `references/pitch.md`）。Word 的待確認清單只留一條聲調總說明，加上內容類的項目。

## 曾經犯過、不要再犯的錯

- 自創標記當成品格式、範例欄位留空，結果成品長得不像原版。
- 把正文寫成課堂摘要（時間戳、經過、零碎的待確認）。
- 把單字放在課外補充前面。
- 照上課順序拆段，同主題分散在好幾處。
- 收了 A／B 對話、換算練習這類課堂操作。
- 想用其他方式繞過被網站擋住的讀取。
- 只交 .docx，App 預覽變成亂碼。
