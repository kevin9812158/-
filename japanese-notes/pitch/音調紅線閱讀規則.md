# 日語音調紅線：人類閱讀規則

## 目的

這份文件說明畫面上讀音上方的紅線應如何被人理解與朗讀。它把日語單字的高低音走勢畫成一張小地圖：紅色水平線表示「這一拍在高音」，紅色向下的直角表示「從這一拍之後降到低音」。除非教材另有說明，這裡採用的是標準日語（東京式）的詞彙音調讀法。

紅線是朗讀提示，不是重音符號、音量符號或字義標記。它回答的是「每一拍相對地要念高還是低」，不回答「要念多大聲、拖多長、帶什麼情緒」。

## 先認識三個讀法

### 一拍

判讀的單位是日語的「拍」（mora），不是漢字數、假名字數，也不是中文的一個音節。每一拍都要依序念出，才能看懂紅線落在哪裡。

例如：

| 讀音 | 拍的切法 | 容易看錯的原因 |
| --- | --- | --- |
| きゃく | きゃ・く | 小寫的ゃ和前面的き合成一拍，不另算一拍。 |
| きって | き・っ・て | 促音っ自己算一拍。 |
| しんぶん | し・ん・ぶ・ん | 撥音ん每次都算一拍。 |
| がっこう | が・っ・こ・う | 促音っ與長音う都各算一拍。 |

若畫面同時顯示漢字和假名，紅線仍是對著「讀音的拍」看；不要用漢字數量去推紅線的位置。

### 高音線

某一拍上方有紅色水平線，表示該拍在這個詞裡處於高音。它不是叫人加重、拉長或提高音量；只要把相對音高維持在較高的位置即可。

連續幾拍的高音，會看起來像一段持續的紅線。實際朗讀時要平順地維持高音，不必每一拍都重新往上跳。

### 下降角

紅色直角出現在某拍右邊時，意思是：

> 這一拍還是高音；它念完後，下一拍開始轉低。

因此，下降角標的是「下降發生在這一拍之後」，不是說該拍本身已經是低音。這是最重要的判讀規則。

## 四種基本走勢

下表用 `L` 表示低音、`H` 表示高音、`┐` 表示該拍結束後下降。這些只是閱讀輔助，真正朗讀時以紅線的位置為準。

| 走勢 | 紅線怎麼看 | 聲音怎麼走 | 接助詞時的判讀 |
| --- | --- | --- | --- |
| 平板型 | 第一拍沒有高音線；從第二拍開始維持高音，詞內沒有下降角。 | 先低後高，並持續在高音。 | 單字末尾沒有下降；後接助詞時，高音通常會延續到助詞。 |
| 頭高型 | 第一拍有高音線，且右邊立刻有下降角。 | 第一拍高；第二拍起低。 | 下降已在第一拍後完成，助詞維持低音。 |
| 中高型 | 第一拍低；中間某一拍開始或維持高音，下降角在詞還沒結束的位置。 | 先低、升高；標有下降角的那拍念完後，詞內後面的拍轉低。 | 因為已在詞內下降，助詞維持低音。 |
| 尾高型 | 第一拍低，之後到最後一拍都在高音；下降角在最後一拍右邊。 | 單字內是先低後高；直到接上下一拍才下降。 | 單字本身看似沒有回低，但助詞通常就是下降後的低音。 |

可以把它想成走樓梯：水平紅線是站在高一階，下降角是「走完這一步才下樓」。所以角落若在最後一拍後面，下降不在單字裡，而是在單字和後面內容的交界。

## 簡化呈現時怎麼看

有些畫面會省略持續高音的水平線，只保留下降處的紅色直角，讓字面較乾淨。這種情況下，直角的規則完全不變；它仍表示「這一拍高，下一拍低」。

閱讀時可補回被省略的走勢：

- 直角在第一拍：第一拍高，之後低。
- 直角在中間某拍：第一拍低，從第二拍高到該拍，接著低。
- 直角在最後一拍：第一拍低，後面都高；接續到詞外才低。
- 簡化呈現明確沒有直角：依平板走勢讀，第一拍低，第二拍起高並延續到後接拍。

但若無法確認畫面是否正在使用簡化呈現，或連直角也可能缺漏，不能由「沒看到線」直接斷定它是平板型；應標示為待確認。

## 由圖到朗讀的固定步驟

1. 只看讀音，先切成拍。
2. 找第一拍：它通常是整個走勢的起點；不要把紅線當成從一開始就一定高。
3. 所有上方有紅線的拍，用相對高音念出。
4. 看到下降角時，保持該拍為高，等它結束後才把下一拍改為低。
5. 若詞內沒有下降角，不要自行在最後一拍降下來；先看是否有後接的助詞或下一個拍可承接那個下降。
6. 把整個詞連讀一次，聽的是「低→高→低」的走勢，而不是逐格念線條。

## 一個純示意例子

以下 `か・な・こ` 只是三拍的示意，不代表特定單字。

| 圖示寫法 | 應讀成 | 常見誤讀 |
| --- | --- | --- |
| `か な こ`，第二、三拍上方有線，沒有下降角 | 低→高→高；若後面還接助詞，高音可繼續。 | 把最後一拍擅自降成低。 |
| `か な┐ こ` | 低→高→低；下降在な念完後發生。 | 把な直接念低，或等到こ念完才降。 |
| `か な こ┐` | 低→高→高；下一個接續拍才低。 | 誤認為こ本身是低音。 |
| `か┐ な こ` | 高→低→低。 | 以為第一拍沒有線就一定低，或把下降拖到第二拍後。 |

## 詞、助詞與句子

紅線最可靠地描述它所覆蓋的那一段讀音。判讀整句時，請遵守以下界線：

- 單字後面有助詞時，要把助詞視為可以驗證下降位置的一拍。平板型會把高音延續到助詞；尾高型則常在助詞處轉低。
- 畫面若把一個表達拆成多段，各段先各自依其紅線朗讀。不要憑空把上一段的高音線延伸到下一段。
- 標點、空白、換行和漢字本身沒有音調；它們旁邊看見紅線時，仍應回頭確認那條線實際覆蓋的是哪一拍的讀音。
- 真實對話還會受句尾語氣、強調、說話速度影響。那些表現不應被用來推翻紅線所指定的詞彙高低走勢。

## 這個符號不表示什麼

為避免過度解讀，紅線不能單獨用來判定下列事情：

- 哪個字比較重要或要加大聲；
- 母音要拉多長；
- 單字的意思、詞性或活用是否正確；
- 整句自然語調的全部細節；
- 未畫出的後續片段究竟會如何連接。

若一段讀音根本沒有可辨識的紅線或下降角，正確結論是「這份材料沒有提供足以判讀的音調資訊」，不是自行猜一種走勢。

## 交給另一個 Agent 的判讀契約

另一套 Agent 只要遵守以下條件，就可用與人類相同的方式解讀紅線：

1. 以讀音的拍為單位，不以文字字元或漢字為單位。
2. 把水平紅線解為該拍的高音。
3. 把右側下降角解為「本拍高、下一拍低」。
4. 沒有下降角不等於全程低音；必須先看高音線從哪一拍開始。
5. 下降角若在末拍之後，必須保留「下降發生在詞後接續處」這個資訊，不能改寫成末拍低音。
6. 分段顯示時，未提供跨段關係就不猜測跨段延續。
7. 資訊不足、線條歸屬不明或來源互相矛盾時，回報待確認，而不是產生看似確定的聲調。

## 最低驗收例

一個符合本文件的判讀者，對下列敘述應都判為正確：

- 「下降角畫在某拍右邊」代表該拍後才下降，而不是該拍已低。
- 小寫拗音和前一個假名合為一拍；っ、ん、長音各是一拍。
- 沒有詞內下降角的平板走勢，不能因為單字結束就自行補一個下降。
- 尾高走勢的下降可由後接助詞顯現，因此不能把詞末高音改判為低音。
- 漢字、標點和換行不能拿來取代讀音拍數做定位。

只要這些判讀一致，人與 Agent 看到同一份紅線時，就會在「哪一拍高、何時下降」這件事上得到相同結論。
