# 日文講義紅線聲調判讀與拆句

把講義上讀音上方的紅線轉成可檢查的聲調資料。單字與例句共用同一套標記，以單字那一套為準。全程使用繁體中文回覆。

## 一、聲調標記（單字、例句統一）

以「拍」為單位，每個語音片段寫成：`型（號數）：每拍高低`。號數 = 下降發生在第幾拍之後；沒有下降為 0。

| 型 | 號數 | 紅線樣子 | 例 |
| --- | --- | --- | --- |
| 平板型 | 0 | 第一拍低，第二拍起高，詞內沒有下降角 | アヒル：ア低 → ヒ・ル高 |
| 頭高型 | 1 | 第一拍高，右側立刻有下降角 | ころころ：こ高，下降 → ろ・こ・ろ低 |
| 中高型 | n（1 < n < 拍數） | 第一拍低，下降角在詞中間 | 勤める：つ低 → と・め高，下降 → る低（3） |
| 尾高型 | n = 該詞拍數 | 第一拍低，到最後一拍都高，下降角在最後一拍右邊 | 坂：さ低 → か高，下降發生在詞後（2） |

規則：
- 拍：小寫ゃゅょ與前一假名合為一拍；っ、ん、長音各一拍。ガチョウ = ガ・チョ・ウ。
- 水平線 = 該拍高；下降角 = 「這一拍高、下一拍低」，不是該拍已低。
- 簡化呈現（只畫下降角、不畫持續高音線）：依規則補回。角在第一拍 → 第一拍高其餘低；角在中間 → 第一拍低、第二拍到角那拍高、之後低；角在最後一拍 → 第一拍低、後面都高、下降發生在詞後。
- 有水平線且沒有下降角 = 平板。完全沒有線 = 待確認，不可當平板。
- 平板與尾高的詞末都是高音，差別在後接助詞：平板後助詞高，尾高後助詞低。尾高必須保留「下降發生在詞後」，不能改寫成末拍低。
- 標準日語（東京式）。號數由紅線推出，未對照字典時要說明。

## 二、讀取方式（先程式、後模型）

腳本：`scripts/pitch_lines.py`（需要 pymupdf、numpy、Pillow、scipy；缺少時 `pip install --break-system-packages pymupdf`）。

```
python3 scripts/pitch_lines.py extract 檔案.pdf --page 1      # PDF：讀向量紅線座標 + 文字層
python3 scripts/pitch_lines.py extract 圖片.png --dpi 300 --crops 輸出目錄   # 圖片：像素偵測 + 裁切小圖
python3 scripts/pitch_lines.py classify "L H H┐ L"            # 對一個詞的每拍標記判定 型（號數）
```

- PDF 有向量紅線時，`extract` 直接輸出每一列的拍與標記（`假名:L／H／H┐`），不需要看圖。沒有向量紅線的頁面會自動改用像素偵測。
- 輸出的是整列原始標記，詞的邊界由你（模型）依語法決定，再把該詞的標記交給 `classify`。`classify` 會補回簡化呈現的高音，並回報 型（號數）；資訊不足時回傳「待確認」。
- 圖片模式的狀態：紅線（線與下降角）的位置偵測已驗證，與 PDF 向量座標 48/48 吻合、誤差小於 1pt。但「紅線對應到哪幾個字格」仍是實驗性質，可能多切或少切，必須對照 `--crops` 小圖人工確認，不可直接採信。
- 不要用整頁縮圖直接判讀；需要看圖時只看裁切後的小圖。
- 線條缺漏、歸屬不明、無法確認是否簡化呈現、讀音看不清：輸出「待確認」，寧可少答也不要猜。
- 使用者沒有明說要用子代理時，不啟動子代理。

## 三、單字輸出格式

兩欄表格：單字、聲調。聲調欄寫「型（號數）：每拍高低」，帶漢字的單字附讀音。

| 單字 | 聲調 |
| --- | --- |
| ガチョウ肉 | 中高型（2）：ガ低 → チョ高，下降 → ウ・ニ・ク低 |
| 働く（はたらく） | 平板型（0）：は低 → た・ら・く高 |

## 四、例句拆解規格

- 拆成「語音片段」（有獨立詞義、需獨立判讀聲調的詞）與「接續文字」（連接用助詞：は が を に へ で と の も から まで より か；連續助詞視為同一段）。
- 每個語音片段保留原文與完整讀音，並有自己的聲調（用上面統一標記）。前一片段的聲調不能拿來猜下一片段。
- 接續文字不另畫紅線，依前一片段承接：平板後為高；頭高、中高、尾高後為低。前一片段待確認，或接續文字在句首無可依附時，標待確認。
- 顯示歸屬：接續文字顯示在前一片段之後（`年を｜取る`），不寫成 `年｜を取る`，也不重複。助詞は讀わ、へ讀え，讀音照實保留。
- 標點是邊界，不是接續文字也不是詞。
- 不為了看起來細而按漢字、假名或拍硬拆；不把名詞、動詞的一部分、形容詞詞尾、助動詞藏進接續文字；不以號數反推切法。
- 詞性、讀音、邊界或聲調不明時保留「待確認」，不以任意切分製造完整答案。

每句輸出：完整原文與讀音；依序的語音片段（文字、讀音、聲調、是否已確認）；接續文字（文字、讀音、承接高或低）；標點邊界；待確認項目與原因。

交付前逐句檢查：片段與接續文字接回後能還原完整原文與讀音；每個實詞、每個助詞恰好出現一次；每個實詞片段有已確認紅線或標待確認；平板後接續文字為高、有下降角的型態後為低；標點沒有被當成詞或助詞。結果存成 Markdown 檔交給使用者。

## 五、暫定慣例（第 1 頁測試時採用，使用者尚未最終決定）

- 擬聲擬態語（コロコロ、ごろごろ）保留為一整段，不拆。
- 動詞後的「て」不拆出來，也不當接續文字。「〜て｜います／いく／きた」在頁面紅線於「て」之後重新起算時拆成兩段；頁面是一條連續走勢（如 遊んでいる）時不拆。
- 終助詞「ね」不在助詞表內：暫列為句末接續文字。注意講義原始標記顯示它沒有紅線，歸類與高低都需使用者決定。
- 同一詞形在不同句子中走勢可能不同（黏塵滾輪的コロコロ = 平板 0；擬態語ころころ = 頭高 1），必須依各自紅線判讀。

## 六、對照資料（L24 單字 2026.04.01 第 1 頁，號數未對照字典）

アヒル 平板 0；ガチョウ 平板 0；ガチョウ肉 中高 2；働く 平板 0；勤める 中高 3；務める 中高 3；ころころ 頭高 1；ごろごろ 頭高 1；コロコロ（黏塵滾輪）平板 0。
