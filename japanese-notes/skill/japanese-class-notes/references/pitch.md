# 聲調

要判讀原版講義上的紅線、做拆句時，用 `japanese-pitch-reader` skill（已安裝在使用者帳號）。這裡只放筆記產生需要的重點。

## 目前規則（使用者指定）

- 逐字稿沒有聲調資料，筆記裡所有詞一律先畫成 0 號音（平板），也就是 note.json 的 `accent_default: 0`。
- 待確認清單的第一條要註明這一點。
- 之後聲調資料會由使用者的 MCP 依 schema 提供，拿到後把號數填進 `#n` 再重新產生。

## 標記

- **統一標記**（單字、例句通用）：`型（號數）：每拍高低`。號數＝在第幾拍之後下降。
  - 0：平板
  - 1：頭高
  - 1 < n < 拍數：中高
  - n＝拍數：尾高
- **怎麼數拍**：小寫的ゃゅょ併入前一拍；っ、ん、ー 各算一拍。
- **紅線的意思**：
  - 水平線＝該拍是高音。
  - 右側的下降角＝「這拍高、下一拍低」。
  - 範本上有時會簡化畫法，要依規則補回。
  - 完全沒有線＝待確認，不可以當成平板。
- **平板和尾高**：兩者詞末都是高音，差在後面接的助詞：平板後的助詞是高音，尾高後的助詞是低音。

## 拆句

- **語音片段**：實詞，各自有聲調。
- **接續文字**：は が を に へ で と の も から まで より か。跟著前一個片段走：前一段是平板，助詞就高；前一段有下降，助詞就低。
- **顯示**：接續文字歸在前一個片段後面，例如「年を｜取る」。
- **讀音**：は 讀 わ，へ 讀 え。
- **邊界**：標點是片段的邊界。
- 判斷不出來就標待確認，不要猜。
