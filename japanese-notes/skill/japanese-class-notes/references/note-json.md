# note.json 寫法

完整範例見 `assets/example_note_L33.json`，內容是 L33 打折主題：課外補充加單字。

## 外層

```json
{
  "header": {"left": "L33 單字", "right": "2026.10.07"},
  "accent_default": 0,
  "blocks": [ ... ]
}
```

`accent_default` 是沒有標號數時預設的聲調。目前一律用 0；有聲調資料之後，在片段後面寫 `#n`。

## 日文行寫法（字串）

| 寫法 | 意思 |
|---|---|
| `／` | 語音片段的分隔。每個片段各自有聲調 |
| `{漢字|讀音}` | ルビ。熟語要逐字寫：`{割|わり}{引|びき}`；熟字訓、數字整組寫 |
| `+助詞` | 接續文字，跟著前一個片段的聲調。讀音和字面不同時寫 `+は=わ`、`+へ=え` |
| `#n` | 這個片段的聲調號數，寫在片段最後；`#null` 代表待確認，不畫線 |
| `#m:0112` | 這個片段（含接續文字）每一拍的高低，直接取自 MCP 的 marks：0 低、1 高、2 高且為最後高拍。下降角只畫在「2 且下一拍是 0」的地方。拍數要和讀音一致，否則退回號數。通常由 `scripts/mcp_apply.py` 自動寫入 |
| `!、` `!。` `!？` `!・` | 標點，自成一段，不畫線 |
| `@A：` | 標籤，不畫線 |

範例：`すみません／!、／{割|わり}{引|びき}+は=わ／{何|なん}{時|じ}+から／です+か／!。`

## 區塊

- `{"type": "title", "text": "課外補充"}`：大標題。課本單元寫「大家的日本語 L33」。標題和子標籤會自動和下一個區塊同頁；要強制從新頁開始，加 `"page_break": true`。
- `{"type": "tag", "text": "單字"}`：黃底子標籤。
- `{"type": "note", "text": "..."}`：橘色＊註解。
- `cards`：詞卡。`per_row` 預設 3，動詞這類比較長的詞用 2。每張卡的欄位：
  - `jp`
  - `zh`
  - `label`：課本編號 `"2."`，或 `"補"`（會加框）
  - `arrow`：橘色語感補充
  - `illust`：插圖，可以是 `null`、關鍵字字串，或 `{source, title, url, image}`。有 `image` 就嵌入圖片，不會顯示出處。
- `bullets`：放在表格外的 • 例句，對應範本詞卡下方的例句。`rows: [{jp, zh, arrow?, bullet?}]`，中文放不下時自動換到下一行。
- `defs`：主題表，例如「「打折」的說法」。
  - row 有 `examples: [{jp, zh, arrow?}]` 時排成三欄「詞｜例句｜中文」。左欄是 `term_jp`（或 `term_zh`），可加 `term_sub`（中文）、`arrow`（語感），並跨列合併。
  - 沒有 examples 時排成兩欄：`zh`，或 `jp_list`。
- `grid`：對照表，例如「「幾折」的說法」。欄位有 `header`、`columns`、`widths`（比例）、`rows`。儲存格可以寫 `{"jp": ...}`、`{"zh": ...}`，或直接寫字串（當中文處理）。整張表不拆頁。
- `sentences`：兩欄句子表。`practice: true` 時用灰色表頭（短句練習）。row 可以帶 `bullet`（例如 `"A："`）和 `arrow`。
- 待確認清單**不是區塊**：寫在 note.json 最上層的 `"pending": [...]`（字串或 `{level, item, basis, action}`），產生器不會印出，交付時在對話中列給使用者。舊的 `{"type": "pending"}` 區塊仍可用，但不要再用（使用者指定 Word／PDF 不放清單）。
