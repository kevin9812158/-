# 插圖

## 規則（使用者指定）

- 預設只用いらすとや。查不到才用其他可以免費使用的圖，用之前先查該站的使用規範。
- 詞卡上不放出處或連結。いらすとや 的規約本來就不要求標出處。其他網站的圖，只有在規約要求標示時，才在待確認清單裡註明。
- 動詞和抽象詞不配圖，比照原版。照片類（店家照、來源不明的圖）不要用。
- 查不到合適的圖時，可以先用意思相近的圖暫代（例如 ディスカウント 用「Price Down!」標籤），並列入待確認清單。使用者不喜歡會說要換。

## いらすとや 規約重點

- 個人、商用、非商用都可以免費使用，不需要標出處。
- 商用時，每件作品最多 20 張；超過的話，每張 1,100 日圓，而且全部計費。
- 禁止把插圖本身當成主體再散布。

## 搜尋與下載

1. 搜尋：抓取 `https://www.irasutoya.com/search?q=<關鍵字>`（關鍵字要 URL 編碼）。在結果 HTML 裡找 `href='https://www.irasutoya.com/20xx/xx/....html'>圖名<`，就能拿到圖名和文章頁網址。
2. 找原圖：在文章頁 HTML 裡找 `blogger.googleusercontent.com/img/...` 的 `/s1600/` 圖檔（有些文章是 `/s800/`），排除 banner、sidebar、button、logo 這類網站裝飾圖。不要用 og:image，那是裁切過的縮圖。
3. 一篇文章裡常有好幾張圖，例如 1～9 割引的單張圖。先下載候選圖拼成一張來看，挑最貼近詞義的那張。
4. 把網址填進 note.json 的 `illust.image`。產生器會自己下載，存到執行目錄的 `images/`（可以用環境變數 NOTE_IMG_CACHE 改位置），等比縮放到最大 100×92pt 後置中。下載失敗時會改放灰色圖名，不會中斷產生。

## 網路

雲端環境的網路要設成 Custom，並允許以下主機：
- www.irasutoya.com
- blogger.googleusercontent.com
- 1.bp.blogspot.com～4.bp.blogspot.com

還是被擋的話，用 `curl -sS "$HTTPS_PROXY/__agentproxy/status"` 查被擋的主機名，請使用者到環境設定補上。不要想辦法繞過。
